# UNAL-projects
Un repositorio para todos los projectos basicos necesarios en la UNAL que su complejidad no amerite realizar un repositorio completo

A repository for all basic or one repository based UNAL project that the complexity is not big enough for a large repo

Ejercicios presentes y ejecución:
* Programación de computadores:
  1. Python equipos: Analisis de un archivo de equipos de futbol con salidas legibles, ejecución con Python directamente desde terminal (no tiene manejo absoluto de directorio)
  2. Python pandas: Analisis de un archivo de peliculas, ejecución con Python directamente, tiene manejo absoluto de directorio, el mismo directorio debe estar el archivo de peliculas para funcionar como esperado
